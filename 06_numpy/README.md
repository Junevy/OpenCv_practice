# 06_numpy 学习内容总结

本目录用于学习 NumPy 的数组基础、数组变形、索引筛选、运算、随机数以及常见数组操作。内容按学习顺序分为 `01_arr` 基础练习和 `02_numpy_100` 综合练习。

## 目录概览

| 目录 | 内容 | 文件数 |
| --- | --- | ---: |
| `01_arr` | NumPy ndarray 基础、数组形状与维度、排序拼接、索引、变形、堆叠拆分、运算和去重 | 8 |
| `02_numpy_100` | NumPy 综合练习题，以及一个空的测试文件 | 2 |

## `01_arr`：ndarray 基础

### [`01_arr.ipynb`](01_arr/01_arr.ipynb)

介绍 NumPy 数组的基本概念和创建方式：

- 创建一维、二维数组，查看 `ndim`、`shape`、`size` 和 `dtype`。
- 使用整数索引和切片访问数组元素。
- 使用 `zeros`、`ones`、`empty`、`arange` 和 `linspace` 创建数组。

### [`02_sort.ipynb`](01_arr/02_sort.ipynb)

练习一维数组排序，以及使用 `np.concatenate` 在不同轴上拼接数组，包括水平和垂直方向的拼接。

### [`03_high_dimention.ipynb`](01_arr/03_high_dimention.ipynb)

创建三维数组，观察高维数组的维度、元素数量和形状，帮助理解多维 ndarray 的层级结构。

### [`04_reshape.ipynb`](01_arr/04_reshape.ipynb)

练习 `reshape` 和 `np.reshape`，在不改变元素数量的情况下改变数组形状；同时使用 `np.newaxis` 增加行维度、列维度或更高维度。

### [`05_index.ipynb`](01_arr/05_index.ipynb)

介绍布尔索引和条件筛选：

- 筛选大于某个值的元素。
- 使用 `|` 组合多个条件。
- 筛选偶数元素。
- 使用 `np.nonzero` 获取满足条件的元素位置，并用这些位置索引原数组。

### [`06_high_op.ipynb`](01_arr/06_high_op.ipynb)

练习较高层次的数组操作：

- 使用 `vstack`、`hstack` 和 `concatenate` 堆叠数组。
- 使用 `hsplit` 拆分数组。
- 对比切片得到的 view 与 `copy()` 得到的独立副本，观察修改是否会影响原数组。

### [`07_calculate.ipynb`](01_arr/07_calculate.ipynb)

介绍数组计算和广播机制：

- 加、减、乘、除、取模、整除等逐元素运算。
- 使用 `sum`、`std` 等聚合统计函数。
- 通过不同形状的数组演示广播。
- 使用随机数生成器生成一维、二维和三维随机数组及随机整数。

### [`08_unique.ipynb`](01_arr/08_unique.ipynb)

练习 `np.unique`：获取一维数组的唯一值、首次出现位置和出现次数，并使用 `axis=0` 或 `axis=1` 查找二维数组中不重复的行或列。

## `02_numpy_100`：NumPy 综合练习

### [`numpy_100.ipynb`](02_numpy_100/numpy_100.ipynb)

这是一个按题号组织的综合练习 Notebook，目前包含 1～42 题，覆盖以下主题：

1. **环境与数组基础**：导入 NumPy、查看版本、创建零向量、计算数组占用的内存、查看函数帮助。
2. **数组创建与形状**：创建指定范围数组、反转数组、生成二维矩阵、查找非零元素、单位矩阵、随机数组和随机统计量。
3. **填充与图案**：边界填充、棋盘格矩阵、位置索引、数组平铺，以及数组归一化。
4. **数据类型与矩阵运算**：结构化 dtype（如 RGBA 字段）、矩阵乘法、条件筛选和原地修改。
5. **通用函数和数值处理**：`sum`、幂运算、除法、`copysign`、交集、平方根，以及 `ceil`、`floor`、类型转换、`trunc` 和取整处理。
6. **日期与内存操作**：生成今天、昨天和明天的日期，生成日期序列，并通过 `out` 参数练习原地运算和避免额外数组复制。
7. **迭代器和排序**：使用 `np.fromiter` 从迭代器创建数组，生成随机数组并排序，使用 `np.add.reduce` 对数组做归约求和。
8. **数组属性与结构化数据**：设置数组为只读，以及准备将随机的 `10×2` 数组转换为结构化数据的练习。

其中第 40 题目前只有标题，没有代码；第 41 题通过关闭 `writeable` 后尝试赋值，用于观察只读数组的异常行为。部分早期题目保留了原笔记中的 `error` 标记，应结合代码运行结果理解。

## 建议学习顺序

建议先完成 `01_arr` 中的 1～5 号文件，掌握数组创建、形状、索引和变形；再学习 6～8 号文件中的拼接、广播、随机数和去重；最后按题号完成 `numpy_100.ipynb`，将各项操作综合起来练习。
